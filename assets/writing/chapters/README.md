## Chapter Anatomy (GDD.md §11.3)

Every chapter (except Region IV's Ensayo chapters) follows:

```
[Posada] ── road ── (encounters) ── [Venture] ── (case) ── [Posada] ── (case: a side path)
          ↑                                              ↑
  anamorphosis                                  a Verdict resolves it
  scattered, optional                           in Book or Reality
```

- One mandatory Venture per chapter
- One optional case (usually 2–4 anamorphoses)
- One Posada (checkpoint, shelf, NPCs)
- One colophon (1605 text, author's voice, between chapters)
